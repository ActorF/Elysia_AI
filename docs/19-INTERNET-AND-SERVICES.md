# Internet 与外部服务

在 **Settings → Internet** 开启联网后，本地 AI 会为普通 Chat 判断是否搜索、查询天气或直接回答，不需要手填 API 密钥。聊天界面显示联网状态并提供设置入口；许可只在当前应用进程有效，重启默认关闭。手动研究工具位于 **Advanced research tools**。

## 自动聊天检索

本地模型先给出受约束的决策。普通闲聊和已提供文本的处理可直接回答；需要核对公开事实时生成搜索查询，需要实时天气时选择专用天气工具。规划输出不合规时最多修复一次，明确的联网要求不会因格式错误而静默退回未经核实的回答。无法安全构造查询或仍无法完成规划时，会明确说明限制。

搜索向固定 DuckDuckGo Lite 端点发送查询，最多取得五份标题、链接和摘要。对当前域名许可内的结果，最多自动读取两页正文摘录；其他结果保留为搜索摘要，不自动扩大网站权限。服务不可用、挑战页或无结果时，最多回退一次到对应语言 Wikipedia，并标明百科来源限制；不绕过挑战。

聊天显示正在判断、搜索、查询天气、阅读资料或整理回答等阶段。正文和摘要都有大小限制，不代表完整阅读整站；当前仍是一轮有界检索，不是持续自主浏览。

规划、搜索和回答属于同一次生成。取消、切换所有者或关闭联网撤销搜索。完整对话、附件、长期记忆和人格提示不发送给搜索服务；模型只在本机用少量近期对话理解问题。查询文字本身会发送给对应网站，应避免包含私人内容。

**重新生成** 和编辑后重试使用当前联网设置重新判断并获取资料，不复用旧答案作为本轮证据；时间问题重新读取电脑时钟。重试取消或失败时保留原来的完整问答。明确要求“不要联网”或“离线回答”会跳过本轮检索。Work 的重新生成仍只改写回答，不重复执行命令。

检索文本作为不可信资料进入回答。程序附上实际来源链接；无可用结果则提示未实时核实。来源块便于核对，不代表每个模型结论都已验证。原消息保持原文；Work 和明确启用 Project Sources 的回答沿用独立流程。

## 时间与天气

普通 Chat 可以直接读取电脑的当前日期、时间和 UTC 偏移，不需要开启联网或运行 CMD。简单的本机时间问题直接由时钟结果回答；其他回答可使用本轮可信时间上下文。电脑时钟及其时区设置决定结果，不能据此猜测用户所在城市或其他城市的当地时间。

天气查询使用用户明确提供的城市，也能接续“天气如何？”后补充城市的对话。没有城市时先询问；地名存在多个匹配时提示候选，不使用 IP 定位或从时区推断位置。联网关闭时提示开启联网，不编造实时天气。

城市由 Open-Meteo 地名服务解析，再读取其当前天气或今天／明天预报。回答区分当前状况与预报，保留地点、提供方时间、单位和来源。更远日期或历史天气不能用当前值替代。这些数据是天气模型结果，不是电脑附近气象站的直接实测。

“那现在呢”等短续问优先采用本条消息指定的时间；“后天”或历史日期不会被前文的“明天”覆盖。包含天气词的诗歌、歌词等创作请求不会仅因关键词而强制查询实时天气。

## 网络边界

| 设置 | 行为 |
| --- | --- |
| 内置服务 | DuckDuckGo Lite、英/中文 Wikipedia、GitHub、Open-Meteo 天气与地名服务、歌词服务无需另加域名 |
| 额外域名 | 只接受精确域名；不接受通配符、URL、端口或凭据，且不包含子域名 |
| 公网读取 | 仅标准端口 HTTPS；DNS 地址检查后固定连接到公开 IP，拒绝私网/回环/链路本地；重定向重新验证 |
| 代理 | 默认直连，不继承系统/环境/PAC；可显式选 `127.0.0.1` 的 HTTP CONNECT 代理与端口 |
| 期限 | DNS、连接、TLS、重定向和响应共用总超时，响应体有界 |

代理失败不回退直连，TLS 仍验证目标证书。关闭 **Allow Internet access** 立即撤销授权；保存设置期间也可独立 **Turn Internet off**。修改策略会取消旧请求，底层资源真正结束前仍显示忙碌。策略按版本原子保存，损坏或保存失败保持关闭。

网页文字不能授权登录、上传、发送、发布或购买。公网开关也不是系统防火墙：独立本地服务、浏览器及在 Work 中另行授权的 CMD 命令自行使用网络。[CMD 权限说明](17-WORKFLOW-AND-DESKTOP-AGENT.md#通用-cmd-执行)介绍这条独立执行路径。

## 本地服务与外部链接

歌词查询也需联网，`lrclib.net` 已内置；关闭授权会取消查询和重试等待，本地音频处理保持原边界。

打开公开 HTTPS 来源链接需联网及原生 URL 确认，但不需要把目标域名加入应用读取许可。浏览器使用自己的 Cookie、登录和网络设置；Elysia 关闭联网不会关闭浏览器或阻止其后续访问。

Ollama、视觉、语音、Embedding 和绘图的本机服务不依赖公网开关。Chat/模型列表只接受本机 HTTP 回环，`localhost` 固定为回环 IP，拒绝环境代理和重定向。旧远程/局域网 Ollama 配置需改为本机地址。

## 高级研究工具

先选定可用的 Chat，再打开 **Settings → Internet → Advanced research tools**。输入、展开表单和查看记录均不自动发请求。

| 工具 | 使用与限制 |
| --- | --- |
| **Search Wikipedia** | 选 English/中文并输入查询；最多五个结果，这是百科检索，不是新闻搜索 |
| **Read page** | 显式 HTTPS URL 或来源直链；最多三次受策略约束的重定向 |
| **Weather** | 手填经纬度，规范到四位小数；不读取系统定位，返回 Open-Meteo 模型估算及单位/时间 |
| **Public GitHub repository** | 手填 owner/repository；固定 API 读取公开资料，无 Token，改名需确认后重查 |

当前 Chat/Project 最多保留十个来源、二十条查询记录。来源显示直链、标题、纯文本摘要、获取时间及可用日期。Wikipedia 最后编辑时间不等于发布日期；GitHub `open_issues_count` 包含 PR，不标为纯 Issue 数。

**Read page** 仅支持 UTF-8 `text/html` / `text/plain`，响应最多 1 MiB、正文 32 KiB，截短会标明。优先 article/main，其次 body；移除脚本、导航和表单，只显示纯文本，不执行脚本或请求图片、样式、iframe。PDF、图片、JSON、其他编码及登录互动不支持。网站声明日期与 HTTP Last-Modified 分开保存，不能据此推算事件时间或认定内容真实。

### 来源审核与草稿

**Review source → Add source to Chat draft** 重验当前所有权后追加带直链的引用，保留已有草稿，不自动发送。

可选择一至五个来源并填写问题、来源陈述/推断、已知事件日期及不确定性。**Compare** 只使用已有资料，提示缺失日期、同域名、缓存或较旧内容，不认定来源独立性或真实性。记录五分钟有效；来源替换/清除或切换 Chat/Project 后失效。加入草稿前重验，最多引用五份有界摘录，并区分来源、用户填写的日期和推断。

研究数据仅存内存。切换 Chat/Project、失去会话权限、关闭窗口或重启会清除；关闭联网保留已获资料供离线查看。短暂断连重连也会撤销旧审核、写入预览和迟到结果。

服务参考：[Open-Meteo](https://open-meteo.com/en/docs)、[GitHub 仓库 API](https://docs.github.com/en/rest/repos/repos#get-a-repository)。

## 创建 GitHub Issue

这是当前唯一外部写入接口：填写仓库、标题和正文，生成五分钟有效的预览，再确认以打开独立原生对话框。对话框显示实际目标和完整内容，默认 Cancel；批准只对本次发送有效。修改内容、切换聊天、关闭联网或改变策略都会撤销旧预览。

启动应用时通过 `ELYSIA_GITHUB_TOKEN` 提供具备目标仓库 Issues 写权限的 Token。Main 捕获后立即从子进程继承环境移除，不写设置、Chat、日志或 Renderer；只有固定 Issue POST 使用它。公开读取无凭据，更新 Token 需要完整退出后重启。接口见 [GitHub 创建 Issue](https://docs.github.com/en/rest/issues/issues#create-an-issue)。

写入禁止重定向和自动重试。关闭联网可撤销未发送请求，已发送内容无法保证撤回。结果区分成功、取消、失败和未知；超时/断开后若不确定服务端结果，应先查仓库。成功地址必须属于已批准仓库。

## 缓存与离线使用

成功的搜索、读取、天气和仓库查询可保存在当前 Chat/Project 的内存缓存：最多二十项、2 MiB，按最久未使用淘汰，不写磁盘、不后台刷新、不在失败后自动替换为旧答案。

**List cached results → Restore cached result** 明确恢复旧资料。搜索、天气、仓库有效期五分钟，网页正文三十分钟；过期需另行确认。恢复保留原获取时间并标记 Cached，恢复时刚过期也要求重新核对。

关闭联网或改域名后仍可离线查看/恢复，不产生 DNS 或网络访问。切换范围、断连、关闭窗口或 **Clear cache and research** 清除缓存及对应资料；重启为空。

## 验证范围

合同、原生传输和 UI 回归覆盖默认关闭、HTTPS/CONNECT/TLS、DNS/证书/超时、取消排空、范围变更、严格来源/日期解析、一次性预览、凭据隔离和缓存恢复。包内离线检查验证关闭状态拒绝五条读取路径，缺 Token 拒绝写入，缓存可恢复且网络调用为零。

实际只读验收包含 Wikipedia、GitHub 和天气；写入使用本机 CONNECT/TLS 合成服务，没有向用户仓库发测试 Issue。本机模型结合真实天气的测试只验证通路，模型仍可能误读资料。回归同时覆盖初始状态乱序、时钟回拨和短暂断连，避免旧资料或批准重新生效。
