# Internet 与外部服务

Stage 12 的公网请求由 Electron Main 统一管理。联网许可只在当前应用进程中有效，每次启动都保持关闭，允许域名默认为空；打开 Settings → Internet，添加所需的精确域名并明确保存后，相关功能才可以请求该服务。域名、代理和超时选择可以保存，界面重载不会被当成新进程。加载设置、打开面板或输入查询都不会自行联网。

## 网络策略

策略包括总开关、精确域名列表、请求总超时和代理选择。域名不接受通配符、URL、端口、用户名或密码；允许一个域名不会自动允许其子域名。公网读取只使用 HTTPS 的标准端口，对 DNS 返回的地址检查后固定连接到公开 IP；私网、回环、链路本地等地址不能通过公网读取接口访问。重定向也必须重新通过策略检查。

默认直接连接，不继承系统、环境变量或 PAC 代理。可明确选择本机 `127.0.0.1` 上的 HTTP CONNECT 代理及端口；代理连接失败时不会改用直连，TLS 仍验证目标网站的证书。请求的 DNS、连接、TLS、重定向和响应都受到总超时约束，响应体有大小限制。

**Turn Internet off** 不需要等待当前请求完成。关闭或修改策略时立即撤销旧授权、请求取消；底层资源真正结束前仍保留忙碌状态。策略采用版本检查和原子保存，损坏或保存失败时保持关闭，不会恢复旧的联网许可。

查询内容和明确选择的 URL 会发送给对应网站；使用代理时代理也参与连接。不要在搜索词或 URL 中放入不希望发送给外部服务的私人内容。网页内容不是操作授权，不能替用户登录、上传、发送、发布或购买。

## 既有功能与本地服务

歌词查询同样需要开启联网并允许 `lrclib.net`。取消网络授权会终止歌词查询及其重试等待；本地音频处理仍按既有边界运行。

打开外部链接需要网络策略允许目标域名，并在原生对话框中单独确认 URL。浏览器使用自己的登录、Cookie 和网络设置；网站打开后，Elysia 的开关不会关闭浏览器或阻止该浏览器后续访问。

Ollama、视觉模型、语音、Embedding 和绘图的本机服务不依赖公网开关。Chat 和模型列表查询限制为本机 HTTP 回环地址，`localhost` 在请求前转为固定回环 IP，并拒绝环境代理和重定向。已有远程或局域网 Ollama 设置需要改为本机地址；当前配置界面会说明该限制。这不是操作系统防火墙，独立运行的本地服务和外部浏览器仍自行管理其网络行为。

人格 Markdown 和本地绘图实现不因联网功能而修改。
