# Internet 与外部服务

Stage 12 的公网请求由 Electron Main 统一管理。联网许可只在当前应用进程中有效，每次启动都保持关闭，允许域名默认为空；打开 Settings → Internet，添加所需的精确域名并明确保存后，相关功能才可以请求该服务。域名、代理和超时选择可以保存，界面重载不会被当成新进程。加载设置、打开面板或输入查询都不会自行联网。

## 网络策略

策略包括总开关、精确域名列表、请求总超时和代理选择。域名不接受通配符、URL、端口、用户名或密码；允许一个域名不会自动允许其子域名。公网读取只使用 HTTPS 的标准端口，对 DNS 返回的地址检查后固定连接到公开 IP；私网、回环、链路本地等地址不能通过公网读取接口访问。重定向也必须重新通过策略检查。

默认直接连接，不继承系统、环境变量或 PAC 代理。可明确选择本机 `127.0.0.1` 上的 HTTP CONNECT 代理及端口；代理连接失败时不会改用直连，TLS 仍验证目标网站的证书。请求的 DNS、连接、TLS、重定向和响应都受到总超时约束，响应体有大小限制。

**Turn Internet off** 不需要等待当前请求完成。关闭或修改策略时立即撤销旧授权、请求取消；底层资源真正结束前仍保留忙碌状态。策略采用版本检查和原子保存，损坏或保存失败时保持关闭，不会恢复旧的联网许可。

查询内容和明确选择的 URL 会发送给对应网站；使用代理时代理也参与连接。不要在搜索词或 URL 中放入不希望发送给外部服务的私人内容。网页内容不是操作授权，不能替用户登录、上传、发送、发布或购买。

## 既有功能与本地服务

歌词查询同样需要开启联网并允许 `lrclib.net`。取消网络授权会终止歌词查询及其重试等待；本地音频处理仍按既有边界运行。

打开外部链接需要网络策略允许目标域名，并在原生对话框中单独确认 URL。浏览器使用自己的登录、Cookie 和网络设置；网站打开后，Elysia 的开关不会关闭浏览器或阻止该浏览器后续访问。

Ollama、视觉模型、语音、Embedding 和绘图的本机服务不依赖公网开关。Chat 和模型列表查询限制为本机 HTTP 回环地址，`localhost` 在请求前转为固定回环 IP，并拒绝环境代理和重定向。已有远程或局域网 Ollama 设置需要改为本机地址；当前配置界面会说明该限制。这不是操作系统防火墙，独立运行的本地服务和外部浏览器仍自行管理其网络行为。

人格 Markdown 和本地绘图实现不因联网功能而修改。

## 搜索与聊天草稿

Chat 下展开 **Internet**，选择 English 或 中文并输入查询，点击 **Search Wikipedia**。这是维基百科搜索，不是全网或新闻搜索；需要分别允许 `en.wikipedia.org` 或 `zh.wikipedia.org`。输入、展开面板和查询记录不会触发自动请求。

每次最多返回 5 个结果，当前 Chat/Project 保留最多 10 个来源和 20 条查询记录。标题、纯文本摘要、直接 URL、获取时间和最后编辑时间均可查看；维基百科不提供可靠的原始发布日期，此字段显示 Unknown，不能把编辑时间当成事件时间。

选择 **Review source → Add source to Chat draft**，程序再次确认来源仍属于当前聊天后，把带直接 URL 的引用追加到最新草稿。输入过的草稿会保留，消息由用户自行审核并发送。来源文字作为不可信资料，不授予登录、上传或执行命令的权限。

查询记录和来源只存内存。切换 Chat/Project、失去会话权限、关闭窗口或重启都会清除；关闭联网保留已获取的资料供离线查看，任何新搜索仍须重新开启。取消保持忙碌状态直到实际网络资源结束。

## 网页正文读取

**Read page** 读取用户明确填写的 HTTPS URL，或当前来源的直接 URL。最多跟随三次重定向，每一步仍须满足精确域名和公开 IP 规则；最终页面地址随来源保存。界面直接显示纯文本，不创建网站窗口，不执行脚本，也不加载图片、样式或 iframe。

读取支持 UTF-8 的 `text/html` 和 `text/plain`，响应最多 1 MiB；正文优先取 article/main，其次 body，移除脚本、导航和表单等内容。正文最多 32 KiB，截短会明确标注。PDF、图片、JSON、登录页后的互动操作和其他编码不是此读取器的功能；失败会显示可重试的类型或编码说明。

页面声明的发布日期和最后修改日期分别保存；HTTP Last-Modified 只可作为修改日期，绝不推算事件时间。日期元数据也属于网站声明，不能据此认定内容已经核实。

## 来源比较、推断与不确定性

可选择 1–5 个当前聊天的来源，填写问题或待判断的说法，明确选择“来源陈述”或“推断”，并分别填写已知的事件日期及不确定性。比较页并列显示直接 URL、发布日期、修改时间和获取时间；缺失日期、同域名来源、缓存或较早获取的资料都会提示。来源是否相互独立、内容是否真实不会被自动认定。

**Compare** 只根据 Main 已获取的来源生成比较记录，不启动新请求。记录有效期为五分钟；来源被替换、清除，或切换 Chat/Project 后失效。加入草稿前再次校验记录与实际来源，引用最多五份有界摘录，清楚区分来源陈述、用户输入的事件日期和推断。仍由用户审核并发送，页面文字不能授权外部操作。

## 天气与公开 GitHub 信息

**Weather** 只使用用户手动输入的经纬度，不读取系统定位。坐标规范到小数点后四位，发送至 `api.open-meteo.com`，返回当前模型估算的天气、温度、湿度、降水和风速，以及单位、数据时间和获取时间。这不是附近气象站的直接观测；结果中的请求 URL 可以直接复查。[Open-Meteo 文档](https://open-meteo.com/en/docs)

**Public GitHub repository** 接受明确的 owner/repository，向固定 `api.github.com` 获取公开仓库的简介、星标数、开放 issue/PR 数量和更新/推送时间。公开读取不附加 Token；仓库改名重定向需要用户确认新名称后重新查询，不自动继续。`open_issues_count` 包括 Pull Request，因此界面不把它标为纯 Issue 数。[GitHub 仓库 API](https://docs.github.com/en/rest/repos/repos#get-a-repository)

两种查询都需先允许相应域名，且只在点击后执行，不需要 API 密钥。返回资料使用同一来源查看、比较和聊天草稿流程，关闭联网后不会自动重试。

## 外部写入与独立确认

**Create GitHub issue** 是当前支持的外部写入。先填写仓库、标题和正文，生成五分钟内有效的预览，再点击确认以显示独立原生对话框。对话框展示实际目标和完整内容，默认选择 Cancel；确认只对这一次发送有效。修改内容、切换聊天、关闭联网或更改策略后，旧预览失效。没有通用登录、上传、发送邮件或购买接口；网页文字不能创建批准。

写入需要在启动 Elysia 时通过环境变量 `ELYSIA_GITHUB_TOKEN` 提供具备目标仓库 Issues 写权限的 GitHub Token。Token 只由 Main 捕获，随即从子进程继承环境移除，不写入应用设置、聊天、日志或 Renderer；仅固定的 GitHub Issue POST 带上授权。公开仓库读取不使用此凭证。完整退出应用并重新启动才会读取新的 Token。[GitHub 创建 Issue 文档](https://docs.github.com/en/rest/issues/issues#create-an-issue)

关闭联网会撤销尚未发送的请求；发送后无法保证撤回已发布内容。结果明确区分成功、取消、失败与结果未知；超时或断开且无法确定服务端结果时，先检查仓库，不自动重发。成功结果只接受与已批准仓库一致的 Issue 地址。所有写入禁用重定向和自动重试。

## 缓存与离线行为

成功的搜索、网页读取、天气和仓库查询会在当前 Chat/Project 的内存缓存中保存。最多保留 20 个结果和 2 MiB 序列化资料，超限时淘汰最久未使用的结果；不写入磁盘，不后台刷新，也不在新查询失败后自动替换成旧答案。

点击 **List cached results** 查看本地列表，再选择 **Restore cached result**。搜索、天气和仓库信息的有效期为五分钟，网页正文为三十分钟；过期项需要勾选使用旧资料的确认。恢复保留原始获取时间并标记 Cached，不能冒充新查询；即使恢复时刚刚过期，也会要求重新查看列表并确认。

关闭联网或修改允许域名后仍可查看和恢复缓存，不产生 DNS 或网络访问。切换 Chat/Project、断开会话、关闭窗口或点击 **Clear cache and research** 会清除缓存及相应研究资料。应用重启后缓存为空。
